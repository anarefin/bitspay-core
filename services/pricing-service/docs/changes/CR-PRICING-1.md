## 1. Motivation
SRS v1.2 (14 Oct 2026) adds the MVP release before R1. Two MVP products are new transaction types owned by transaction-service: `BILL_PAY` (BIL-011, internal biller catalogue, simulated biller settlement) and `RECHARGE` (BIL-012, mobile recharge via the MNO catalogue, simulated fulfilment). transaction-service evaluates their fees in-process from `fee.rules` (pricing-algorithm v1), so pricing must accept plans for both types and seed one plan each. This moves SRS FEE-006 biller fees from Deferred to Build (MVP). Biller commission stays Deferred (R1). Fee values are provisional under SRS B-26. Module `campaign` is R1+ and is not deployed in the MVP (`bitspay.modules.campaign.enabled=false`).

## 2. Change (before → after)
- `codes/planTxnType`: {P2P, CASH_IN, CASH_OUT, MERCHANT_PAYMENT, MERCHANT_REFUND, FLOAT_TRANSFER, REVERSAL} → + `BILL_PAY`, `RECHARGE`.
- `codes/planWalletType`: {C, A, D, M, I} → + `B` (BILLER, the payee wallet of BILL_PAY / RECHARGE).
- OpenAPI (`info.version` 1.0.0 → 1.1.0): `txnType` enum + `BILL_PAY`, `RECHARGE` in `PlanJson`, `PlanDefinition`, `PlanHeader`, `PricingQuoteRequest`, `Accrual`, `StatementLine`; wallet-type enum + `B` in `PlanJson.match.payer/payeeWalletType`, `PlanDefinition.match.*`, quote party `walletType`. Campaign enums (`TriggerSpec.txnTypes`, `SegmentClause.txnType`) and `IncentiveRuleDefinition.txnTypes` are unchanged (R1+).
- Events: `fee.rules/PRICING_PLAN_UPSERTED` `txnType` + `BILL_PAY`, `RECHARGE`; `match.payerWalletType` / `payeeWalletType` + `B`. `commission.events/COMMISSION_ACCRUED` `txnType` + `BILL_PAY`, `RECHARGE`.
- `data/pricing-algorithm` v1: input `txnType` enum + `BILL_PAY`, `RECHARGE`; `walletType` + `B`; step 0 comment (payee B → payer category). The steps and the golden vectors are unchanged.
- New rule BR-PRC-64: a `BILL_PAY` / `RECHARGE` plan must have `commission.type = NONE` (biller commission R1); `match.payeeWalletType` null or `B`.
- Seed plans (§8.3): `PLN-BILL-STD` BILL_PAY, FIXED 500 poisha, PAYER, VAT 1500 bps, commission NONE; `PLN-RECHARGE-NONE` RECHARGE, fee NONE, OPERATOR, commission NONE.
- SPEC: DDL CHECKs, §1.3 removes "no biller txnType exists", §2 traced to SRS v1.2 with an `MVP?` column (+ BIL-011, BIL-012), §10 `[MVP]` / `[R1+]` tags + WP-CR-1, §11 tests, §13 OPEN D-45 / B-26, §14 row.
