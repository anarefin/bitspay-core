## 1. Motivation
SRS v1.2 (14 Oct 2026) adds a new release value **MVP** that precedes R1. Its supporting capabilities include "basic KYC with compliance screening": AML-001, AML-002, AML-003, ONB-008, ONB-011, PON-004, PON-005, BOM-004/005 and REF-05 are delivered in the MVP. The MVP also introduces biller partners (BIL-011 internal biller catalogue, BIL-012 mobile recharge via the operator catalogue): wallet-service onboards them as partner type `BILLER` (sub-types `UTILITY`, `EDUCATION`, `GOVT_FEE`, `INTERNET_TV`, `MNO`) with a type `B` settlement wallet, through the normal partner onboarding path, so they reach compliance in `PENDING_SCREENING`. AML monitoring (AML-004, CIC-010), alert / fraud cases (AML-006, FRD-008/010/011), freezes and instructions (AML-009, PON-009), CTR / STR / regulatory reporting (AML-005, AML-007, AML-011, RR-06/07) move to R1+; AML-008, AML-010, FRD-012, ARC-002 stay R2. None of the withdrawn v1.2 IDs (GLD-031, INT-01, B-18) or reworded LED-014 / A-37 are referenced by this pack.
